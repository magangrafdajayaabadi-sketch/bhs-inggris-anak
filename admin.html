Mode server: verifikasi sandi dilakukan di server (aman untuk produksi). Mode lokal: proteksi sisi-klien saja — cukup untuk mencegah pengguna biasa, tapi bukan keamanan tingkat server (lihat README).

Ekspor & impor konfigurasi

Mode lokal: pengaturan admin tersimpan di browser ini saja. Agar branding berlaku permanen untuk semua pengunjung, salin konfigurasi lalu tempelkan ke file js/config.default.js sebelum deploy — atau aktifkan mode server (lihat README).

Ekspor untuk cadangan, atau impor konfigurasi dari file JSON.
